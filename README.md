# Gestão de Produção de Aeronaves - SPA React

Este projeto é uma aplicação web em React para gestão da produção de aeronaves, incluindo cadastro, consulta e administração de aeronaves, peças, etapas, testes, funcionários, relatórios e estatísticas.

## Começando

Para rodar o projeto localmente, siga os passos abaixo:

### Instalar dependências

npm install

### Rodar em modo desenvolvimento

npm start

Abra [http://localhost:3000] no navegador para visualizar a aplicação.

A página recarrega automaticamente ao modificar o código.

## Funcionalidades principais

- Sistema SPA com navegação sidebar fixa.
- Cadastro, edição, exclusão e consulta (CRUD) de várias entidades.
- Filtros e buscas dinâmicas.
- Dashboard com estatísticas resumidas.
- Interface responsiva e gráfica.

## Tecnologias usadas
